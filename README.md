# Peaceful-Biomes-Fabric-Forge.Neoforge-1.20.1-

Спокойный мод для Minecraft (Fabric, Forge, Neoforge 1.20.1): новые биомы, блоки, расслабляющие механики.

## Установка

1. Установи загрузчик (Fabric/Forge/NeoForge 1.20.1).
2. Помести файл мода в папку `mods`.

### Зависимости

- Нет обязательных зависимостей.
